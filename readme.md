# mhermes.kr 사이트 파일 안내

- index.html 홈 / location.html 입지 / units.html 상품안내 / faq.html Q&A / consult.html 상담 / privacy.html 개인정보처리방침 / 404.html 오류 페이지
- style.css 디자인(색상은 맨 위 :root 부분)
- robots.txt, sitemap.xml 검색엔진용 / og-image.png 카톡·SNS 공유 이미지 / favicon.svg 탭 아이콘 / _headers 보안 설정

## 공개 전 반드시 바꿀 값 (모든 html 파일 공통)
- 010-0000-0000, 01000000000 → 실제 상담 번호
- https://pf.kakao.com/_XXXXXX → 카카오톡 채널 주소
- 노란 표시(분양대행 상호·대표·사업자번호 등) → 실제 값
